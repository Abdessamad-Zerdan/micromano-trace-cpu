\# MicroMano Trace CPU



Microprogrammed Mano-style CPU implemented in Verilog HDL.



\## Features



\- Microprogrammed control unit

\- Datapath / control unit separation

\- Microcode ROM and sequencer

\- Verilog implementation

\- Vivado RTL elaboration and simulation

\- Self-checking testbench

\- SWAP instruction support

\- Trace/debug outputs



\## Project Structure



\- `src/` : Verilog source files

\- `sim/` : testbench files



\## Tools



\- Verilog HDL

\- Vivado 2019



\## Verification



The processor was verified using:

\- Behavioral simulation

\- Waveform analysis

\- Self-checking testbench
